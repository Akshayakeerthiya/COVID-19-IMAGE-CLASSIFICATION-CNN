# COVID-19 Image Classification using Deep Learning

## Project Overview
This project focuses on classifying chest X-ray images as **COVID-19** or **Normal** using Deep Learning techniques. It implements an end-to-end deep learning pipeline, including data preprocessing, exploratory data analysis (EDA), CNN model development, model training, and model evaluation.

## Features
- Data preprocessing and image normalization
- Exploratory Data Analysis (EDA)
- Data visualization
- Convolutional Neural Network (CNN) model development
- Model training and validation
- COVID-19 image classification

## Technologies Used
- Python
- TensorFlow
- Keras
- NumPy
- Pandas
- Matplotlib
- OpenCV
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Load the chest X-ray dataset
2. Preprocess and normalize the images
3. Perform Exploratory Data Analysis (EDA)
4. Build and train the CNN model
5. Evaluate model performance
6. Classify chest X-ray images as COVID-19 or Normal

## Evaluation Metrics
The model performance was evaluated using **Accuracy** and **Loss** during the training and validation process.

## Results
The trained CNN model successfully classifies chest X-ray images into **COVID-19** and **Normal** categories, demonstrating the effectiveness of deep learning for medical image classification.
